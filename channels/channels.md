# 渠道表

> 每个渠道都写清楚"怎么抓、产出多少、怎么失败"。失败方式比成功经验更重要，因为它会静默污染语料。实测时间：2026-11。

## A. 发现：融资与项目

| 渠道 | 用法 | 实测效果 | 坑 | 建议 |
|---|---|---|---|---|
| AI 搜索 + 公众号 AI 搜索 | 问"近期完成 X 轮融资的 AI4S 公司" | 适合起步扩池 | 海外公司没注册公众号就搜不到 | 保留，作为起点 |
| ai4s.fyi `/funding` | 直接抓，结构化 | 10 月全球约 32 轮的骨架 | "在谈"和"已完成"混在一起；核查日期会过期 | 保留，逐条回原文核实 |
| 36 氪 | 正文在 `window.initialState` 的 JSON 里 | 国内首发报道多 | 移动端抓不到；直接抓只有导航 | 保留，写专属解析器 |
| 量子位 / 机器之心 | RSS、官方 JSON 接口 | 技术成果多 | 通用抓取只回几百字；接口不能翻页 | 保留 |
| 微信公众号 | wechat2rss 镜像 | 最近几天的内容 | 每号只回最近 10 条；原文有滑块验证 | 只用于短窗口 |
| 投资界 / 科创板日报 / 亿欧 | 搜索 + 抓取 | 国内早期融资的二次确认 | 常常只是公司稿的转载 | 保留，按同源去重 |
| TNW / TechCrunch / EU-Startups / Sifted / Business Wire | 搜索 + 抓取 | 海外融资首发 | 部分站点拒绝抓取 | 保留 |
| newmarketpitch / 赛道融资追踪页 | 抓取 | 按赛道汇总 | 二手整理 | 只用于扩池 |
| 企名片 / IT 桔子 / 烯牛 / 鲸准 | 人工登录，按赛道 + 时间 + 轮次筛选 | 最全 | 付费 | 人来操作，导出后交给 agent |
| Reddit / Product Hunt | 搜索 | 海外早期产品 | 噪音大 | 用于人物信号 |
| 丁香园 | 搜索 | AI 制药的临床阶段 | 只适用于制药 | 垂直使用 |

## B. 发现：人物与技术信号

| 渠道 | 用法 | 实测效果 | 坑 | 建议 |
|---|---|---|---|---|
| GitHub 搜索接口 | `created:` + `stars:` 按周切片 | 3 个月 780 个高星新仓库 | 单个仓库和用户的接口可能受限 | 主干 |
| arXiv API | `search_query` + `sortBy=submittedDate` | 唯一稳定、免费、带日期的学术源 | 无 | 主干 |
| Hugging Face | 官方接口不通时改用镜像 | 下载量、gated 状态 | 官方接口可能不可达 | 保留镜像路径 |
| OpenReview | 个人档案 | 教育经历和年份（本人自填） | 无 | 用于核实年龄 |
| 个人主页 / 简历 PDF / Gist | 直接读 | 最硬的时间线 | 可能过期 | 用于核实年龄 |
| 学校公示（奖学金、去向名单） | 搜索 | 机构背书的入学年份 | 分散 | 用于核实年龄 |
| 播客 / 技术博客 / X | 搜索 | 判断创始人的表达和影响力 | X 无接口，转帖放大严重 | 不作一手源 |
| Digclaw（科创人才意图雷达） | 申请试用 | 社交动向、技术栈更新、开源贡献等信号 | 面向企业客户，未见公开注册 | 待试用，适合作信号层 |

## D. 抓取质量判据（见 `scripts/quality_checks.py`）
1. 正文少于 800 字符：基本等于抓到了导航或登录框
2. 标题里的独特关键词在正文中命中 0 次：抓错了页面
3. 出现"浏览器版本过旧""环境异常""扫码下载 App"：页面被污染
